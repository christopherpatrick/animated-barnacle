# animated-barnacle

A small browser game: guide a wiener dog around the yard, eat bones, dodge fire hydrants, and unlock new breeds. Open `index.html` in any modern browser to play, or visit https://christopherpatrick.github.io/animated-barnacle/.

## Controls

- Move: arrow keys / `WASD` / swipe
- Pause: `P`
- Restart: `R`
- Mute: `M`
- Start / resume: any direction or `Space`

## Items

- Bone — +1 point
- Golden bone — +3 points
- Sausage — slows time briefly
- Tennis ball — phase through walls and yourself briefly

## Obstacles

Fire hydrants spawn every 5 points. Phase mode lets you pass through them.

## Breeds

Unlocked by your best score:

- Dachshund — default
- Corgi — 5 points
- Poodle — 15 points
- Pug — 30 points

Best score and selected breed are saved in `localStorage`.
